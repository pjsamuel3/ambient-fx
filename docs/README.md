# docs

Prompts are stored two ways: the user's original wording (verbatim) and a restated
specification an agent can act on directly. Read the specification; consult the
verbatim text if intent is unclear.

- [prompts/01-aurora-particles-brief.md](prompts/01-aurora-particles-brief.md) — the original brief (already detailed), with a short clarifications section.
- [prompts/02-gradient-and-palettes.md](prompts/02-gradient-and-palettes.md) — gradient version, shared palettes, hue/saturation controls, extra vibrant colours.
- [prompts/03-aurora-light-layer.md](prompts/03-aurora-light-layer.md) — continuous aurora light layer and dot-visibility fader.
- [prompts/04-theme-export-embed.md](prompts/04-theme-export-embed.md) — Dark/Light toggle, Settings JSON export/import, embeddable `mount()` / `<ambient-fx>`.
- [prompts/05-remaining-experiments.md](prompts/05-remaining-experiments.md) — the four remaining gallery experiments: ripple grid, particle field, fluid simulation, noise waves.
- [rebuild-notes.md](rebuild-notes.md) — decisions, conventions and tuning that the prompts alone don't capture.

If the code is lost, feed an agent the prompts in order, then the rebuild notes.
